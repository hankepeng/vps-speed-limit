# vps-speed-limit v1.0.0

服务器带宽限速脚本（菜单式），用于防止腾讯云 / 阿里云轻量服务器因长期占满带宽被官方降速到 1Mbps。

支持同时限制「上传(出口)」和「下载(入口)」带宽，重启后通过 systemd 自动生效；内置 Ookla Speedtest 测速、测速历史与快捷命令 `vsl`。

## 功能特性

- 自动识别服务器主网卡（ens5 / eth0 / ens18 等）
- 同时限制上传(出口)与下载(入口)带宽，填 0 表示不限速
- 上传限速：`tc` HTB 直接加在网卡上，不区分协议
- 下载限速：IFB 虚拟网卡 + HTB，ingress filter 使用 `protocol all`，同时覆盖 IPv4 / IPv6
- 生成 systemd 服务，重启后自动生效
- 快捷命令 `vsl`（大小写不敏感），输入即可打开菜单
- 内置 Ookla Speedtest 测速，自动安装 speedtest CLI
- 测速实时动态显示，保存最近 3 次完整结果、时间与平均值
- 菜单内一键更新脚本到最新版本

## 一键安装 / 打开菜单

```bash
bash <(curl -Ls https://raw.githubusercontent.com/hankepeng/vps-speed-limit/main/bandwidth-limit.sh)
```

运行后自动进入菜单，并自动安装 `vsl` 快捷命令。

## 快捷命令

```bash
vsl          # 打开菜单（大小写均可，如 VSL、VsL、vSl）
vsl -t       # 直接测速，跳过菜单
```

## 测速功能

- 自动检测并安装 Ookla Speedtest CLI（优先 apt，失败时用官方二进制）。
- 测速时实时显示动态进度。
- 结果保存到 `/root/speedtest_history/`；菜单选 5 查看最近 3 次完整结果、时间与平均值。

## 限速原理

- 上传（出口）：`tc` HTB 队列直接限制网卡出口速率，不区分协议。
- 下载（入口）：入口流量先经 ingress filter 重定向到 IFB 虚拟网卡 `ifb0`，再在 `ifb0` 上做 HTB 限速；filter 使用 `protocol all`，同时覆盖 IPv4 与 IPv6。

> 说明：tc 限制的是网络层（IP 包）速率，Speedtest 显示的是应用层有效数据速率，两者之间约有 5% 的协议头开销，因此测速结果略低于设定值属正常。

## 常见问题

**为什么设置 180Mbit，测速只有约 170Mbps？**

tc 限的是 IP 层速率，Speedtest 显示的是应用层（TCP 载荷）速率，中间的 TCP/IP 与以太网协议头约占 5%，属正常现象。

**下载限速为什么不生效？**

请确认服务器是否启用了 IPv6。旧版本 filter 只匹配 IPv4（`protocol ip`），会导致 IPv6 下载流量不被限速；v1.0.0 已改为 `protocol all`，同时覆盖 IPv4/IPv6。

## 卸载

在菜单中选择「4) 永久取消限速」即可，会删除服务、脚本与 `vsl` 命令。
